# 真实 Work 验收

这些测试需要真实 ChatGPT 项目设置和新建对话。CLI 与独立 agent 探针只能提供补充证据。每项记录时间、工具、实际源 SHA、期望、观察和脱敏证据。

| 测试 | 操作与可观察结果 | 初始状态 |
| --- | --- | --- |
| 新建对话 | 复制入口后新建 Work 对话，要求先报告实际 SHA，再完成任务 | not-run |
| 项目隔离 | 两个项目各自运行任务，未读取另一项目业务状态 | not-run |
| 任务内固定版本 | 任务 A 开始后更新稳定指针，A 继续使用原 SHA | not-run |
| 新任务升级 | 任务 B 开始后读取新指针，使用新 SHA | not-run |
| 压缩恢复 | 长任务压缩后从回执恢复 SHA、完成项及未完成项 | not-run |
| 加载失败 | 用不存在的路由测试，说明缺失，停止依赖操作 | not-run |
| 工具缺失 | 关闭检索或生图能力，保留可独立完成部分 | not-run |
| 私有仓库 | 使用获授权的私有副本测试读取和拒绝访问路径 | not-run |

当前目标仓库为公开仓库，不能把公开读取成功当作私有授权测试通过。不要为测试临时改变本仓库可见性。
