# reading-preview 独立发布与入口检查

日期：2026-10-30。基线：9c7e696d0f185c3c93f58544364b4ea71133e08e。范围：修复短入口指向不存在频道造成的 404，保持 stable 和学术 preview 不变。

## 观察与根因

真实阅读任务报告 main 的 channels/reading-preview.json 返回 404，未声称加载远程工作流。仓库核查确认目录当时仅有 stable.json 与 preview.json，而伴读短入口直接要求读取 reading-preview。该次任务的 workflow_sha 保持 unknown；上述基线是本轮核查源码，不能追溯改写真实任务的加载记录。

旧 validate 只遍历已有频道文件与指令图，没有检查短入口声明的分发依赖。源码合并与频道发布各有证据义务，不能用合并成功或静态通过代替入口可用。

## 修复边界

入口增加 schema 1 YAML 元数据，声明项目、仓库和频道。validate 检查正文与元数据一致、频道与发布记录一致、频道包含对应项目的正确路由、项目不重复。缺失频道不会回退到 stable。该检查离线执行，不获取远程源码、不验证模型语义行为，也不证明项目设置已经保存。

reading-preview 仅分发 interactive-reading。先为已存在且 CI 通过的基线创建 v0.3.0-rc.1 记录，再为含入口检查的已验证新源创建后续不可变记录。两个既有频道不参与切换。用户明确授权本次独立预览发布；未授权、也未执行 stable 晋级。
