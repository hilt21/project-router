# 设计库候选验收

## 测试任务

为电机械制动写一篇微信贴图短文并审校，给一张 3:4 单色编辑封面方案。封面标题逐字保留「制动状态如何验证？」。当前阶段只输出配方和提示词。

| 检查 | 预期 |
| --- | --- |
| 正文阶段 | 审校条目只加载一次，技术事实和不确定性保留，标题含标点不超过 20 字 |
| 视觉阶段 | 单色海报入口、模板、验收清单按需加载，明确画幅、纸色、单墨与原文 |
| 工具 | 本任务无生图动作，另测显式生图请求和缺少工具时的阻塞 |
| 普通任务 | 无匹配时基础内容执行包不读设计库文件 |
| 复现 | 本地锁和回执可追溯到 router SHA、设计库来源 SHA 和读入文件 |

命令和阶段参数见 [内容工作流使用说明](../CONTENT.md)。真实新建 Work 项目对话、单图实际工具调用及回滚后的宿主行为待验。CLI 回归只证明路径选择和静态契约。
