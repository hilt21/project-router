## 故障与边界检查

- 不完整扫描、重复 ID、分页证据缺失和账户不匹配不能导入。
- 采集失败不覆盖成功输出；部分结果写入单独诊断文件。
- 同步保留人工备注、类型判断、取消收藏来源及其关联记录。
- 仓库改名继续使用数字 ID，历史读取记录保留原仓库名和版本。
- 生成地图过期、来源元数据漂移、读取版本不一致和无证据宿主通过声明均被拒绝。
- 显式把 catalog 路径加入 route includes 时，编译器拒绝；正常执行包不包含候选技能正文。
- 采集脚本拒绝非 GitHub API 分页目标。

本次未更改活动注册表、技能锁、路由正文、bootstrap 或频道。当前 stable 仍指向 v0.1.2，preview 仍指向 v0.2.0-rc.2。目录在仓库中显式检索，已有项目入口不会自动获得候选发现行为。
