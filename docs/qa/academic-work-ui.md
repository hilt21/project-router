# 科研候选版真实 Work 界面验收

日期：2026-10-25，Asia/Shanghai。对象：preview `v0.2.0-rc.2`，固定源 SHA `5010dce4d4b2edc1b18398a5f868cb8cf5a10cfc`，源 tree `7a6d3ae2c6c9da44957c78b0d7d6d142f2c10074`。

## 方法与环境

用户明确授权登录和创建临时 QA 项目，并完成账号验证。通过浏览器可见界面确认已登录，创建专用临时项目，将候选快照中的 `bootstrap/academic-research.md` 原文保存到项目说明，再打开设置回读并比较一致。选择“工作”模式，创建三个真实 Work 对话，提交四轮合成请求。界面模型选择器显示 GPT-6.1 Sol；本轮未比较其他模型。

宿主项目创建界面提示“仅限项目的记忆”无法使用云端 Work。本轮使用默认记忆，因此这里只观察 research_id 对回复内容的约束，不声称宿主记忆在项目间隔离。没有更改仓库可见性或用户已有项目设置。公开证据只保存合成输入说明、观察摘要、公共规则元数据和入口安装截图，不包含账号信息、私有对话链接或完整聊天记录。

## 实际结果

| 场景 | 输入与判定标准 | 可见观察 | 结果 |
| --- | --- | --- | --- |
| A1 数学新任务 | `work-qa-a`：在方形域上最小化 x²，原稿以半正定 Hessian 和三个采样点断言严格凸、唯一驻点及唯一最优解 | 固定到 rc.2 和上述 SHA；进入 math；指出函数不严格凸，驻点条件只约束 x，最优解集为 {0}×[-1,1]；有限采样不能证明唯一性 | passed-scoped |
| A2 读取记录与回执 | 同一研究只整理已有读取记录，并返回可传递的 JSON 清单，不为填表再次读取 | 表列 12 个文件路径、ref、blob SHA 及全文声明；缺失的精确行范围与读取时 main commit 写 unknown；JSON 保留四项错误主张、未验证项及无正式 passed 审查的状态 | passed-scoped；正文读取声明仍有验证限制 |
| B 缺材料与隔离 | `work-qa-b`：明确检查数学证明，但不附命题、证明或公式；不使用其他研究材料 | 保持 math / blocked；要求准确命题、完整证明、定义与假设；正文没有引入 A 的公式、结论或审查；材料、主张及审查记录均为空 | passed-scoped；单例未观察到内容串用 |
| C 新对话恢复 | 将 A2 实际生成的 JSON 清单交给第三个 Work 对话，只作为历史记录，没有原稿或新证据 | 保留 work-qa-a、同一 SHA、math；历史 complete 只表示前次检查完成；错误主张仍为 refuted / invalid-proof；材料摘要未知时不擅自判 stale，也没有升级为当前 passed 或投稿通过 | passed-scoped；仅回执交接 |

三个对话的回执均称使用 `audit-mathematical-rigor` 与 `verify-delivery`，以 document 方式全文读取，并将正文 SHA-256 与 lockfile 的一致性列为未验证。未观察到生成的研究文件或数值实验产物；本轮没有独立审计宿主文件系统。

B 的宿主自动生成标题出现了与任务无关的后缀。正文没有出现该后缀或 A 的材料。本轮不把标题异常推断成记忆泄露，也未验证其来源；后续隔离验收仍应覆盖宿主记忆和标题生成。

## 读取证据的等级

A1 展开后的可见活动中出现获取交付验证技能的工具活动，最终答复和 A2 回执列出了版本及读取记录。验收侧另用 GitHub 连接读取固定源 tree，逐项核对回执中的 11 个规则、配置和技能文件 blob SHA；频道指针的第 12 个 blob SHA 与 main 的独立回读一致。12 项均匹配，详见 [结构化观察](academic-work-ui-observations.json)。

元数据匹配提高了回执可核对性，但当前界面未提供完整逐项工具输入输出，因此不能把回执自述等同于“已独立观察全部全文读取”。全文范围、读取顺序及 Work 内 SHA-256 校验继续保持未验证。恢复对话不读取频道指针是其可见回执声明，本轮没有取得覆盖全部工具调用的独立日志。

入口设置的局部截图见 [安装证据](academic-work-ui-bootstrap.jpg)。截图只说明入口存在于专用 QA 项目设置；它不证明数学正确性、读取覆盖或恢复通过。

## 未测范围与发布处理

本轮没有执行真实宿主上下文压缩、从持久化 passport / claim ledger / audit ledger 恢复、频道更新竞争、两个宿主项目隔离、关闭工具后的降级、加载失败、私有仓库授权、真实研究文件变更、真实论文效果或领域专家复核。样例正确不能推出其他数学问题可靠，也没有无技能基线或模型独立性证据。

候选源代码、技能、lockfile、频道及已有 release 文件保持原值；本报告是后续 QA 证据补充。发布时记录的 not-run 和认证阻塞保留其历史含义，最新范围以 [Work 验收](../WORK_ACCEPTANCE.md) 为准。stable 仍未推广到科研候选版。
