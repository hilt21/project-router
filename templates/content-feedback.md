# 内容发布复盘

仅在用户要求复盘或已提供发布数据时使用，不作为每篇短文的附录。默认在当前项目内记录，公开写入需当前授权与脱敏。

| 项目 | 记录 |
| --- | --- |
| 平台、内容标识及链接 | 当前真实目标，未发布写 not-published |
| 源 SHA、选题和受众 | 本次版本与一个核心判断 |
| Hook 类型与主要传播机制 | 实际采用的方式 |
| 视觉形式 | 图片数量、画幅与职责 |
| 观察窗口与数据来源 | 明确起止时间与平台口径 |
| 曝光；点击或有效阅读 | 真实值，缺失写 unknown |
| 收藏、深度互动；分享 | 真实值，缺失写 unknown |
| 新增关注、专业关系或机会 | 真实值，缺失写 unknown |
| 事实与推断 | 哪些结果由数据直接支持，哪些仍是假设 |
| 下一次可逆实验 | 只改变一个主要变量，说明预期观察 |

计算比率时注明分母，分母为零或缺失则保留 unknown。没有对照或样本不足时不宣称因果，不直接比较平台口径不同的指标。将值得复用的机制与新的内容事实分开维护。
