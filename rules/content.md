# 创作目标与硬约束

将研究、技术发现、个人思考和实际经验转化为有传播价值的内容。兼顾 Attention（停留）、Value（收益）、Trust（可信）、Sharing（传播）和 Retention（长期关注）。坚持受众视角、独立洞察、证据、清晰和平台适配，用最少的文字与图片传递足够信息。事实准确性是硬约束，传播维度按内容优化，不机械打分。

## 六个传播机制

每次创作都考虑六项，优先选一个最强角度，不把内部检查表强加到发布正文。

| 机制 | 决策问题与约束 |
| --- | --- |
| Relevance，与我有关 | 具体受众是谁？事件与其痛点、利益或决策有什么关系？ |
| Curiosity，认知反差 | 真实冲突或信息缺口是什么？正文必须及时兑现 Hook，禁止夸张标题。 |
| Value，内容收益 | 快乐、知识、共鸣或可执行价值在哪里？用信息增量和节奏控制阅读负担。 |
| Credibility，可信证据 | 用一手资料、原始数据、真实截图、Demo 或可验证案例支持关键判断。 |
| Social Currency，社交货币 | 分享能表达什么专业判断、身份或价值观？读者能否用一句话转述？ |
| Compounding，长期积累 | 是否强化长期内容定位？复用已验证机制，避免复用过时事实。 |

避免利用焦虑、愤怒和夸大结论换取停留。独立判断需要证据和边界，避免将信息罗列包装为洞察。

## 搜索与证据

涉及最新技术、研究、产品、行业动态或具体外链时，先核实关键事实。只引用非中文网站，优先原始研究、官方文档及一手资料。用户提供的中文材料可作为输入并标明性质。只提供中文证据时明确缺口。

区分来源直接确认的事实、作者的观点或观察、创作者的推断，以及当前未知。人物的感受、比喻和短期访问不能自动扩展为总体结论；事件关联不能单独证明人物动机或唯一目的。只核实确有必要的数字；证据不足时删去、缩小主张或保留待核实标记。禁止编造数据、直接引语、亲身经历和来源。

引用帮助读者核验，不堆砌来源。创作底稿保留主张与来源的对应关系，发布正文只保留必要出处。历史文案和先前模型回复只提供任务背景，事实仍需重新核实。

## 内容与视觉

先确定核心观点，再选摄影、信息图、结构图、对比图等形式。第一屏说明受众为什么应关注，标题和封面提供合理的信息缺口，正文及时兑现。

让图片展示证据、解释机制或降低认知负担。保持手机可读性和清楚的信息层级，避免装饰性 AI 画面、虚构截图、错误数据和无信息量的图表。精确数据图使用绘图工具。

需要生图时默认先规划视觉 Token：画幅、构图、视觉主体、信息层级、配色、字体、图文关系与平台适配。用户直接要求生成时，在内部完成必要规划并直接调用宿主生图能力，不额外等待确认。只交正文或视觉方案时不越过所请求的阶段；发布需当前授权与工具确认。

## 发布前检查与复盘

逐项检查停留、价值、可信、记忆、分享和关注：谁会停留，新增什么，证据支持什么，能否一句话复述，为什么会分享，如何强化长期定位。缺少明确传播价值时先调整角度。质量判断采用短理由，不用总分替代事实检查。

发布后只记录可获得的真实数据：曝光、点击或有效阅读、收藏及深度互动、分享、新增关注和高质量专业关系。记录平台、观察窗口、选题、Hook 类型、传播机制、视觉形式与表现；缺失值保留 unknown，未发布标为 not-published。跨平台指标不直接比较。

使用 [复盘模板](../templates/content-feedback.md) 提出有证据的下一轮可逆实验。没有数据时只形成待验证假设，不声称传播效果已经提高；不因一次表现就升级通用规则。
