# 构图选择与反例

## 技术标本

主题为“制动状态如何验证？”时，technical-specimen 将一个夹钳主体放在页面中下部，主体约 55%，留白约 45%。标题和三个待验证问题沿同一边缘排布。图中没有资料支持的传感器或内部机构应省略。

常见失败是将概念标注画成实际安装位置。修正时将标注移动到图外，用问题表达，并保留主体本身。

## 封面主体

editorial-cover 用较大主体和标题形成接触关系，标题可压住留白边缘，完整中文字符保持可读。辅助信息只承担来源或必要解释。

常见失败是为制造“设计感”加入多个徽章、无用序号和装饰线。逐项检查它们是否帮助读者理解或行动，再删掉冗余项。

## 系列一致性

六张独立图片使用相同纸色、墨色和事实标注方式，各张分配自己的主题与画幅。逐图提示词应保留该张的原文，不能把六张主题拼进一张画布。字形错误时只修复出错图片，并核对其余文字。
