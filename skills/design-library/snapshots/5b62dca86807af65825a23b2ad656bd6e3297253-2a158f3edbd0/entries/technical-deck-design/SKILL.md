# 技术演示稿设计

1. 写清听众、演讲时间和希望听众带走的判断。从材料提取事实，每个量值带单位和来源。
2. 每页记录论点、证据、视觉表达、口头讲解和编辑对象。按读者理解顺序安排页面。比较用同维度图表，结构用示意图，动态过程用分镜或演示。
3. 决定哪些对象应在 PowerPoint 中编辑。标题、正文、表格和需要更新的数据图表优先用原生对象。截图和照片记录来源与裁切。用户提供模板时保留版式和主题。
4. 交付逐页规格。需要 PPTX 时由宿主生成、渲染并检查所有页面。抽查正文文本框和关键图表可编辑性，确认字体、对齐、外溢和来源标注。
