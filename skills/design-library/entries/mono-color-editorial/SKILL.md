# 单色编辑海报

1. 确认渠道、受众、画幅、用户原文和交付阶段。逐字保留指定文字。没有指定文字时沿用渠道语言；用户要求无字时省略文字。先交付方案的任务停在方案。
2. 为主题选择一个主体。参考照片提供主体身份和事实依据，保留辨识特征。将参考版式拆成可复用的视觉关系，再设计原创构图。
3. 输出配方，记录纸色和墨色的 HEX 值、主体位置和占比、主要留白区、标题层级以及网点或印刷纹理。明确单墨时只使用一种墨色，纸色与网点深浅用于产生层次。双色要求才开启第二种墨色，并分别定义功能。
4. 按 PROMPT.md 写最终提示词，按 CHECKLIST.md 审查。当本轮明确进入生图阶段时，把已核对提示词交给宿主的既有生图流程。
