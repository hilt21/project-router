# 单色海报提示词模板

必填输入：渠道、画幅、主体、需要保留的辨识特征、纸色、墨色、版式、网点处理、语言和标题原文或无字设置。

拼装为一份提示词：为「{渠道}」设计一张「{画幅}」编辑海报。用「{主体}」承载核心判断，并保留「{辨识特征}」。纸色「{纸色}」，墨色「{墨色}」。按「{版式}」安排主体、留白与标题。印刷质感使用「{网点处理}」。按「{语言及原文字段}」渲染文字，禁止擅加文案。使用原创构图。输出与指定画幅一致的一张画布。

多张独立图时按每张图的输入各实例化一次，由宿主按图片 ID 执行。
