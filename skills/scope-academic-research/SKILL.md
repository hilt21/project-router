# 定义研究问题

先读取同快照的[科研契约](../../workflows/academic-state.md)。使用当前请求、已有专业背景、材料和约束；不要重复询问已知信息。

1. 确认研究对象、实际问题、目标读者、可用数据和计算或实验条件。将未知条件明确列出。
2. 把研究目标写成可测量、可证伪的问题。用户要求探索时可提出标明为工作假设的候选问题；尚未收敛时保持暂定状态。
3. 区分已有知识、拟议贡献和待验证预期。列出最接近的竞争研究或待检索对象，不把尚未检索的空白认定为创新。
4. 对每个拟议主张，定义对照、指标、成立范围、替代解释，以及什么证据会推翻它。先设计证据获取方案。
5. 将关键假设、资源依赖、可逆实验和可能迫使研究改向的条件交给下一阶段。必要时只询问最能改变研究设计的缺失条件，并继续独立工作。

交付研究问题说明：对象与范围、问题、候选贡献、关键假设、反证条件、验证计划和下一步文献检索。未知证据不写成研究发现。完成条件是研究问题与验证方法已经足够明确；研究方向由作者决定。
