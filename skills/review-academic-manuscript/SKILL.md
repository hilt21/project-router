# 评审、修订与复审

先读取同快照的[科研契约](../../workflows/academic-state.md)。接收当前稿件、证据账本、既有问题和修订前版本；明确本次要求评审、修订或复审。

1. 从创新与定位、方法和数理、文献与论证、反例与替代解释四个视角审查。按任务裁剪，不要求固定数量的 agents；角色名称、数量或一致意见不能证明独立性。
2. 每项发现记录稳定 ID、稿件位置、证据、严重程度、对结论的影响和可验证修复。分开记录确定错误、合理疑问和未知；缺少材料时指出需要哪项材料。
3. 提供有依据的修订顺序，优先核心结论、公式、数据与引用。保留冲突意见，不通过模型评分、投票或虚构编辑决定宣布论文可接受。
4. 修订时逐条对应问题 ID、采取的动作、修改位置、证据和验证结果。意见存在错误时给出依据并记录未采纳理由；不机械接受全部意见。
5. 比较原稿与修订稿的公式、数值、符号、单位、引用、保护术语和断言强度。检查相关变因果、可能变确定、边界被移除等漂移。原证据不足以支持更强主张时收回或补证。
6. 复审修改项、其依赖及遗留问题，保留原失败记录。材料改变后使相关审查过期；复核通过后按契约明确替代旧记录。

交付带证据的发现清单、逐条回应与修订对照、复审结果、遗留问题。明确这属于辅助审查；真实期刊决定需要期刊的实际通知，不能由模拟角色产生。
