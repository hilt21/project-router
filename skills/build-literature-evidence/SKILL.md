# 建立文献与证据体系

先读取同快照的[科研契约](../../workflows/academic-state.md)。接收研究问题、现有文献、稿件及检索限制。优先原始论文、数据和官方材料，引用遵守项目来源范围。

1. 记录检索日期、数据库或网站、查询式、时间范围、纳入排除条件、检索停止依据及未覆盖范围。使用关键词检索，并对关键文献正向、反向追踪引用。
2. 覆盖奠基研究、最接近的竞争研究、反面结果和边界。按问题、方法、假设、证据、局限及与本研究关系建立文献矩阵。以覆盖关键论证为目标。
3. 分开检查 Reference Existence 与 Claim Support。存在性核对标题、作者、年份、DOI 或其他标识；支持性需要实际读到的具体段落、公式、图表或数据。记录只读摘要、部分正文、全文或访问失败。
4. 没有检索结果时标记 unknown，不能据此认定文献虚构。DOI 能解析、元数据匹配或文章被收录，均不足以证明当前主张得到支持。区分相关性、因果性、样本范围和定量值。
5. 比较最接近的已有研究在问题、方法、理论结果、实验和工程意义上的差异。新颖性结论必须绑定检索范围和日期；搜索未发现相同工作不能证明全球首次。
6. 给重要主张分配稳定 ID，登记准确表述、来源定位、实际取得的材料与核查状态。保留反证、支持冲突及未检查项；参考文献数量不能替代论证覆盖。

交付文献矩阵、创新对照、检索日志和主张证据账本。核心支持缺口明确列出补充阅读或实验步骤；不要用模型记忆填补来源。
