# 写作与排版学术稿件

先读取同快照的[科研契约](../../workflows/academic-state.md)。盘点研究问题、文献、证明、实验和目标期刊；本次只要求提纲或润色时交付对应范围。

1. 建立章节与主张、证据、推理的映射。工程论文可采用适用的 IMRaD 结构，按学科与期刊调整。通常先处理方法和结果，再整理背景、讨论与摘要。
2. 事实、引用、方法和数值必须来自本次已取得的材料。将缺口标为 [MATERIAL GAP]；可继续写有依据的部分。Methods 只描述实际执行的程序；计划用未来或计划语态。
3. 明确区分观察、解释、因果、理论结论与应用预期。限定条件、否定结果和不确定度必须保留。不得把相关性改成因果，把数值样本改成证明，把仿真改成现场验证。
4. 检查每个核心论点的支持路径与反面证据。Discussion 解释机制、竞争方法更好的条件、局限及还不能支持的主张。避免用更多引文或公式数量替代论证。
5. 读取实际目标期刊的官方指南，记录来源和获取日期。使用官方模板与可编辑公式，统一符号、单位、公式与图表编号、坐标、图注、交叉引用和参考文献。要求未知时保留待核实。
6. 导出 DOCX、PDF 或 LaTeX 时，调用宿主实际支持的能力并检查渲染、公式、图表和引文；未导出或未看渲染结果时明确未验证。稿件修改后保留版本并重查受影响的证据绑定。

交付本次要求的稿件或提纲，以及材料缺口、主张位置和排版验证状态。若允许补充检索，先取得并登记新证据再写入事实。不要编造实验、引文、定量结果或期刊查重阈值。
