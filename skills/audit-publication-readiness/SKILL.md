# 检查投稿前置条件

先读取同快照的[科研契约](../../workflows/academic-state.md)。绑定实际稿件、研究 ID、工作流 SHA、证据及审查版本；重新检查修改过的材料。

1. 盘点已登记主张、引用、公式、实验、图表和候选未登记主张。报告分母、已检查数量、抽样范围和未检查项；账本覆盖率不能证明全文提取完整。
2. 核对文献存在与主张支持两个维度。对核心数学结论核对假设与证明，对实验结论核对实际数据、对照及可复现证据。相关审查必须绑定当前输入，旧 passed + stale 不计为当前通过。
3. 检查已知错误、未解决审稿意见、反例和结论边界。虚构研究记录、核心公式错误、核心结论缺证据和重大引用问题是阻断项，其他优势不能抵消。
4. 核对原创性、引文归属和重复发表风险。网络检索只能做启发式预审；专业相似性报告作为独立输入，记录检测系统、日期和排除设置并解释匹配。没有报告时标记该检查未运行，不编造重复率。禁止回译、换词或扰乱字符来掩盖来源。
5. 读取目标期刊当前官方规则，记录期刊、文章类型、来源日期及具体要求。按实际适用规则检查结构、模板、引用、图表、数据代码可用性、AI 使用披露及投稿附件。期刊未知要求不能记为通过。
6. 按 coverage、reference-existence、claim-support、mathematical-rigor、experiment-validity、novelty-scope、originality、journal-compliance、review-resolution 形成审查记录。不适用项给理由；不要为无数学或实验主张的论文虚构证明或实验。
7. 有本地记录与工具时运行只读 academic-check；它只检查登记契约与一致性，eligible-for-human-review 不能充当科学有效性或录用保证。最终投稿决定由作者核查证据后作出。

交付投稿前置条件表：通过、失败、未知、未运行、不适用分别列出，附当前证据、阻断项及修复顺序。只有适用检查均有当前可核查依据时，才形成供作者最终审阅的材料包。实际投稿、联系编辑或上传未公开材料沿用当前用户授权。
